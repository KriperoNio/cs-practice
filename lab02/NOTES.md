Describe local Git states

Локальный контроль версий - это git, хостинг репозиториев и версионирования -
github.

Staged & Unstaged два этих состояния, до Staged в work dir'ry изменения лежат
локально

Использованные команды
git status показывает текущую ветку (HEAD указатель), index, пути,  и изменения.
git diff показывает изменения которые готовятся к индексации
git diff --staged показывает изменения в состоянии Staged те готовые к выклад'ю

Ветки
ветка новый указатель на коммит. при слиянии создается новый коммит.
