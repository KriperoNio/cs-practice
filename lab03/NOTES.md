git diff HEAD~2 HEAD -- lab03/calc.py
Показывает разницу в изменениях. При этом промежуточное состояние смешивается.

git show HEAD~1 
Отдельный КОНКРЕТНЫЙ коммит.

git log -S"def" --oneline -- lab03/calc.py
Поиск def в файле. Я не писал def (исправлю по необходимости)

git blame lab03/calc.py
Построчная информация изменения файла.

git restore
Востанавливает файл по последнему коммиту.

git restore --source=...
Восстанавливает файл по метке.

git reset --hard 
Это удаление коммита из истории. (reflog в помощь)
В случае работы в комманде разработчк просто может сослаться 
на несуществующий коммит. Ветка на него ссылается и тп. Что
вызовет уйму проблем если злоупотреблять.

git revert
Создает новый хэш, он сохраняет коммит в истории и тем самым
не нарушает целостности графа.

tag от branch
И то и то являются по сути указателями.
